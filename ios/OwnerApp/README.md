# Owner iPhone app

## Target stack

- Swift 6
- SwiftUI
- SwiftData for local cache
- Secure cloud API for shared data and role authorization
- MapKit for address navigation and route ETA
- Keychain plus device authentication for sensitive local credentials

## First modules

- Authentication and owner session
- Today dashboard and calendar
- Client directory and secure access details
- Appointment editor and employee assignment
- Message approval sheet for On Our Way and review requests
- Employee activity, photo review, and panic alerts

## Important implementation rules

- The app must never send an On Our Way message without owner approval.
- The app must not expose access details in list cells, push notification bodies, or screenshots generated by app features.
- Route ETA must be recalculated immediately before drafting the message.
